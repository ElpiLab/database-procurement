HOW TO TEST THIS PROJECT:
1. Open Oracle SQL Developer and connect to a schema.
2. Open the file "2_Database_Setup/setup_database.sql".
3. Run the entire script (Press F5). This will create all tables, constraints, and insert all the mock data.
4. Open any of the query files in the "3_Queries" folder and run them (Press F5 or Ctrl+Enter).
5. The logical and relational models are provided in the "1_Models" folder.

NOTE ON QUERIES:
The queries use SYSDATE to calculate dates (e.g., "past 12 months"). 
They will return the exact results shown in my screenshots when run on the current system date.
