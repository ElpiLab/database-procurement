# KSBL MedSupply ERD

This folder contains the logical entity relationship diagram for the KSBL MedSupply procurement database.

## Diagram requirements

The final diagram should show:

- `SUPPLIER`
- `PRODUCT`
- `SUPPLIER_PRODUCT`
- `DEPARTMENT`
- `EMPLOYEE`
- `PURCHASE_ORDER`
- `ORDER_POSITION`
- Primary keys and foreign keys
- Relationship cardinalities
- Mandatory and optional participation where applicable

## Planned files

- `ksbl_med_supply_erd.pdf` — readable version for submission
- `ksbl_med_supply_erd.png` — image version for the README or presentation

The diagram must match the SQL schema in `documentation/medsupply_ksbl_oracle_ddl_v4.sql`.
